# TimeTrackerXS
A lightweight macOS menu bar app for tracking time across multiple named timers.

## Features
- Run multiple named timers simultaneously
- Group timers — assign timers to named groups, with a running total shown per group
- Live elapsed time display in the menu bar
- Rename timers and edit elapsed time manually
- Export session data as CSV or JSON
- Crash recovery — running timers are preserved across unexpected app restarts
- Persists state automatically between launches
